## Wilmot, *Structure of the Cayley–Dickson algebras*

- **Tables 2, 4, 5, 6 and 14 reproduce exactly** for 𝕆, U₁ (16), U₂ (32), U₃ (64), U₄ (128) with the engine's
  natural graded order (`hav wilmot U4`, about one second). U₅ runs under `npm run test:nightly`.
- **Prose counts differ from the paper's own tables.** The text says 𝕊 has 84 A, 112 C, 224 X triads and
  that U₂ has 1092 B, 336 A. Table 4 implies 84 A, 84 C, 252 X for 𝕊 (28 AAA cycles, 28 CCX, 64 XXX, plus
  28 C and 32 X non-cycles) and 1092 A, 336 B for U₂. The engine matches Table 4; the fixtures use those values.
- **Split zero divisors.** Theorem 10's condition a² = b², c² = d² is not applied to the split cases in the paper's
  own Table 17 (a = o₁₂u₁ with a² = +1 against b = o₁ with b² = −1). Without that condition the engine gets
  12 for A₀,₃ (split octonions), 84 for A₃,₁ and 180 for A₀,₄, as in Table 14; A₂,₂ and A₁,₃ also give 180,
  consistent with the paper's isomorphisms. `zeroDivisorTriads(A, { requireEqualSquares: true })` restores the
  strict condition.
- **Zero-divisor pairs are counted as index partitions.** A four-set {a, b, c, d} with a⊕b = c⊕d has three
  pairings, and a triad (b < c < d) names the pairing that puts the missing element with b. Counting triads
  gives A + B (1428 for U₂); counting distinct pairings gives Z_m (1260), which is what the closed form
  Z_m = (N−1)(N−3)(N−7)/16 counts. Both are available; `zeroDivisorCount` is the latter.
- **Cycle/mode classes.** Joining zero-divisor pairings by the 3-triad-cycle maps and the four modes gives
  7 classes in 𝕊 (the seven primaries of Table 9) but 105 in U₂, not 147. The paper's 147 counts entries in
  Tables 10–13, where each AAA entry expands to 12 pairs and each BBA entry to 6, and overlapping cycles are
  listed under separate entries. The engine's classes are the connected components of the same expansions;
  the two conventions partition the same 1260 pairs differently. Reconciling this needs the paper's exact rule
  for when an overlap is a new entry; deferred.
- **P₁₂ and P₁₄ are graded-isomorphic to P₄ = M(ℍ).** Table 6 identifies the quasi-octonion subalgebras by
  their A/B/C/X counts in the ambient graded order. Those counts are not isomorphism invariants: permuting the
  roles of b, c, d permutes A, B, C. The engine finds an explicit signed relabelling (verified) from the
  reference P₁₂ ⊂ U₂ generated by (o₁, o₂₄, o₃₄₅) and from P₁₄ ⊂ U₃ generated by (o₁₄, o₂₅, o₃₆) onto
  P₄ ⊂ 𝕊, and all three have dim Der = 6 and 12 two-term zero-divisor pairs. So every basis quasi-octonion of
  U₂ and U₃ is a copy of M(ℍ): 105 in U₂, 1085 in U₃ (`hav wilmot T --iso`). Wilmot's type-count census
  (Table 5) remains reproducible as the default and is kept as the "natural order" classification.

eigenvalues; annihilator dimensions 2 / 6 / 4.
